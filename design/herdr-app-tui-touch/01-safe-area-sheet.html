Tradeoff: closest to today's sheet, so the desktop rail and the collapsed face stay familiar. Two-cell tab rows cost vertical space; on a very short phone the last rows scroll instead of shrinking.

Fixes: P1 the tap target is three rows with a blank row above it; P2 every tab target is two rows; P3 the selected band covers both rows; P4 the action row sits on a distinct surface band with boxed buttons and stays last as the terminal height changes with the keyboard; P5 the header reports workspace, path and tab count, and the close control is a single `x`; P6 overflow text moves to a deeper-indented second line.

Data source: the separator row reads the selected tab's terminal name and attach state from the shared document plus `terminal.list`. There is no command field in the current core response, so the artboard does not invent one.

Palette: Gotham Default from terminalcolors.com. Background, foreground, selection, blue, magenta, cyan, green, yellow and red come from its Alacritty export; the panel tint is a derived one-step lift from the background.
