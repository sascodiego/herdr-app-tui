Tradeoff: the needs-you answer is first without scrolling, but the panels change position, which can break muscle memory. The band above already shows the attention glyph, so the reordering repeats a known signal rather than a new one.

Fixes: P1 both panels keep the two-row item rule; P2 only the panel order and the initial selection change; P3 attention is still glyph plus word on row two; P4 one blank row separates panels and the selected band covers both rows of its item.

Data source: order is derived from the same `App::counts` attention grouping used by the phone band. No new state is persisted.

Palette: Gotham Default tokens from `design/system.md` only. No animation; reduced-motion needs no exception.
