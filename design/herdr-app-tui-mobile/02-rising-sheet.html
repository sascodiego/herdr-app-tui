Tradeoff: one component serves both breakpoints — a sheet on a phone, a left rail on a desktop — so there is one set of sections to build and test, and the open phone view keeps nine rows of real terminal. Cost: with the soft keyboard up the sheet has to shrink to a few rows, and it shares the lower half with the terminal emulator's own key bar.

Fixes: P1 workspace once, in the header; P2 tabs carry their agent; P3 menu in one dim footer; P4 glyph plus word per agent; P5 the terminal stays readable behind the open sheet, so switching never costs sight of the work.
