Tradeoff: keeps the muscle memory of today's overlay at the lowest implementation risk, and fills the empty half with information instead of padding. It still covers the terminal while open, so on a phone you cannot watch an agent while you pick the next one.

Fixes: P1 workspace named once, in the header; P2 tabs carry the agent that lives in them; P3 menu demoted to one dim footer row; P4 every agent row states its condition with glyph and word; P5 the selected agent's tail output replaces the dead rows.

The collapsed face is the same in all three directions. Only what opening does is a decision, which is why the toggle affordance can be built once.
