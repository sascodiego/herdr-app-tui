herdr-app-tui — terminal design system

Warm charcoal ground, bone-white text, one Rust orange accent kept under ~10% of the painted area. Palette from the Aprende Rust design system; label and rule discipline from the Claude Code usage dashboard; two-row badge items from the herdr web UI. Kept inside the cell grid: one font size, one glyph family, one-cell gutters, no sizes, radii or shadows.

✓ The active item is a one-cell accent rail plus a wash fill across both rows.
✓ Sections are uppercase muted labels followed by a hairline rule.
✓ A child tab steps two cells right; no connector lines.
