herdr-app-tui — terminal design system

Inherited from the sibling repositories: the app's neutral tokens and the TUI's default catppuccin theme. The cell is the only unit. No sizes, radii or shadows, because a terminal has none.

✓ Header left is the space, right is the core and connection.
✓ The active tab is marked in the list, never restated in the header.
✓ One blank row between groups, never two.
✓ Footer actions are one dim row, separated by two spaces.
△ A helper row indents 4 columns, never more.
✓ No bottom status bar: the header carries connection, the terminal emulator's own key bar carries keyboard hints.
