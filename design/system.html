herdr-app-tui — terminal design system

Warm charcoal ground, bone-white text, one Rust orange accent kept under ~10% of the painted area. Palette from the Aprende Rust design system; label and rule discipline from the Claude Code usage dashboard; three-panel structure and two-row items from the herdr web UI. Kept inside the cell grid: one font size, one glyph family, one-cell gutters, no sizes, radii or shadows.

The desktop rail keeps this geometry at 34 columns with a compact one-row header, on the left.
✓ Three fixed panels: 01 AGENTS (pinned), 02 WORKSPACES, 03 TABS, each with a numbered header and a rule.
✓ Every open agent stays listed and actionable, whichever space or tab is active.
✓ Every item owns two contiguous rows: indicator plus name, then contextual detail.
✓ The active item is a wash fill plus a one-cell rust-line edge. No bright rail.
✓ The active space and the active tab are highlighted in different panels.
✓ Only core-reported data: branch, state word, app, elapsed, panes.
✓ Overflow clips between whole blocks with dim ↑ N / ↓ N lines.
✓ No bottom status bar: connection is in the band, hints in the emulator key bar.
